## Ограничения

- **Публичный репо (ADR-001, ADR-009):** `meta_out.txt` и любой полный инвентарь
  схемы вендора в `lombard-ops` НЕ коммитятся. В публичный репо уходит только
  производный маппинг used-полей (`02 §3`, `/connector/mapping.json`).
- **Схему не угадывать (05 §I):** любая строка маппинга — из `meta_out.txt`.
  Колонки, которых в файле нет, — CONTEXT GAP, не заглушка с догадкой.
- **Семантика ≠ структура (ADR-011, ADR-013):** файл даёт имена, типы и описания
  вендора. Он НЕ даёт подтверждения смысла. Каждая строка маппинга получает
  колонку «оракул» с одним из значений: `metadata_descr` (описание вендора),
  `confirmed_live` (подтверждён SELECT'ом в T-0-3), `hypothesis` (только имя/тип).
  Строка со значением `hypothesis` не используется в формулах 03 §4.
- **ПДн:** файл содержит только метаданные, но при цитировании описаний в
  артефактах — проверить отсутствие примеров с ПДн.
- **Модель исполнения (05 §I):** Sonnet пишет скрипт разбора + ожидаемый вывод;
  запускает Ilyas на своём Маке и возвращает логи; done только после
  подтверждённого человеком лога.
