# BRIEF · M-4 · Механика: хук коммита, самотест, скрипт статуса

**Класс задачи:** A
**Параллель:** нет   (задача правит инварианты, которые проверяют все остальные; пересечение с
любой пишущей задачей неизбежно по построению)

**Файлы на запись** (полный список; на нём МЕХАНИЧЕСКИ проверяется пересечение):
- `tools/session_status.sh` — состояние старта сессии одной командой
- `tools/hooks/pre-commit` — механические инварианты коммита
- `tools/hooks/selftest.sh` — самотест хука, пер-проверка
- `reference/M-4_hook_measurement_2026-XX-XX.md` — артефакт замера

## Цель

Правила репозитория, которые можно проверить машиной, должны проверяться машиной. После задачи
коммит с подменённым содержимым документа, с решением без строки в оглавлении, с исчезнувшей
строкой без переноса в архив, с правкой состояния без обновления даты, с расходящимися множествами
идентификаторов, с кириллической буквой внутри латинского идентификатора и **с раскрытым
секретом** — не проходит. И, что не менее важно, коммит нормальной работы проходит без единого
ложного срабатывания.

## Входные артефакты

- **Разбор оригиналов** — `reference/ARCH_METHOD-UPGRADE_2026-08-07.md` §11.3. Там поимённо
  перечислены семь ловушек рабочего хука и три оси замера, которых в обобщённом пересказе нет.
  Каждая ловушка куплена отказом; ниже они вынесены в шаги как требования, а не как советы.
- Список категорий запрета — `ADR-001` дословно.
- **Чужие номера решений в перенос не идут.** Оригиналы плотно ссылаются на свой журнал; всплывший
  чужой номер есть дефект переноса.

### Семь ловушек, которые обязаны быть закрыты в коде (не в комментарии)

1. **Класс гомоглифов — альтернация целых символов, НЕ диапазон в скобках.** Под байтовой
   семантикой диапазон над многобайтными символами распадается на байты, и ведущий байт совпадает
   с любой кириллицей. Форма: перечисление символов через `|`.
2. **`awk`, а не `sed`, при извлечении множеств идентификаторов.** BSD-версия `sed` на macOS не
   понимает конструкцию, на которой это было написано у донора, и проверка **молча падала**.
   Проект идёт на macOS — это прямо наш случай, а не чужой.
3. **Чтение файла из индекса — без пайпа в `head`.** Иначе на файле больше буфера пайпа приходит
   сигнал обрыва и проверка отваливается на большом документе.
4. **Подсчёт совпадений вместо раннего выхода** при поиске по всему патчу — вход обязан дочитаться
   до конца по той же причине.
5. **Сравнение МНОЖЕСТВ идентификаторов, а не строк**, в проверке «строка исчезла»: иначе
   переформулировка существующей строки даёт ложный позитив, и хук начнут обходить на каждой правке.
6. **Терминатор региона задаётся точно.** Извлекатель, не закрывающий блок на верной границе, даёт
   ложное срабатывание на легитимном входе — у донора это отдельный названный класс отказа с двумя
   инстансами.
7. **Проверка гомоглифов scoped на идентификаторы намеренно.** Обычные композиты русской прозы
   легитимны; правило, срабатывающее на них, будет отключено за неделю.

**Жёсткая зависимость.** Проверки 2, 3 и 5 адресуют `06_INDEX.md`, `07_GAPS.md`, `07_ARCHIVE.md`.
Их нет на диске → `CONTEXT GAP`, задача не начинается: хук, поставленный раньше задачи `M-2`,
будет краснеть на легитимном входе и будет отключён в первую неделю.

## Ограничения

- К БД PawnShop эта задача не обращается.
- Класс A: пишет в репозиторий, коммитит локально. Публикация наружу — класс B, вне scope.
- **Обход хука без явного апрува Ilyas запрещён** — включая собственные проверочные коммиты
  этой задачи, кроме шага замера, где обход и есть предмет измерения.
- Скрипт печатает вердикт **положительным счётчиком**. Голый листинг каталога запрещён: пусто и
  один служебный файл выглядят одинаково.

## Шаги

1. **`tools/session_status.sh`.** Печатает пять счётчиков: изменённые файлы, файлы буфера кроме
   служебного, рабочие деревья, ветки сессий, отставание от опубликованной ветки. Каждый счётчик —
   число плюс совпавшие строки. Вердикт: «ЧИСТО» с кодом 0 либо «НЕ ЧИСТО» с ненулевым.
   **Адаптация под этот проект:** каталога буфера пока нет — он принадлежит **отложенной части**
   `ADR-025`. Отсутствие каталога **не есть отказ** — это ожидаемое состояние; печатать «буфер не
   заведён (отложенная часть ADR-025)» и не завершаться с ошибкой. У донора отсутствие каталога
   означало отказ среды, потому что у него буфер введён; прямой перенос той ветки дал бы у нас
   ложный стоп на каждом старте.
   **Счётчики деревьев и веток `s/*` — не опция, а принятая часть `ADR-025`:** закон «одно рабочее
   дерево на сессию» механической проверки не имеет и держится именно этим счётчиком. Счётчик,
   который не печатается, правило не поддерживает.
   Опубликованная ветка существует — проверено:
   `git remote -v` печатает `origin`, ветка `origin/main` присутствует.

2. **`tools/hooks/pre-commit`.** Семь проверок:
   1. первая строка нумерованного или подчёркнутого документа = имя файла;
   2. append решения в журнал ⇒ строка в `06_INDEX.md` тем же коммитом;
   3. строка с идентификатором исчезла из `07_STATE.md` или `07_GAPS.md` ⇒ `07_ARCHIVE.md` в том же
      коммите. **Сравниваются МНОЖЕСТВА идентификаторов**, а не строки: переформулировка строки не
      должна срабатывать, иначе проверку начнут обходить на каждой правке;
   4. правка `07_STATE.md` ⇒ обновлён `updated_at`;
   5. множества идентификаторов индекса вопросов в `07_STATE.md` и полного реестра `07_GAPS.md`
      совпадают; расхождение печатается с обеих сторон поимённо;
   6. кириллические гомоглифы внутри латинских идентификаторов. **Класс символов задаётся
      альтернацией целых символов, НЕ диапазоном в скобках:** под байтовой семантикой bracket над
      многобайтными символами распадается на байты и совпадёт с любой кириллицей — после чего
      проверка будет отключена в первую неделю;
   7. **проверка на секреты в патче** — специфичная для этого проекта, репозиторий публичный.
      Категории — из `ADR-001` дословно. Проверка печатает совпавшие строки с номерами; **пустая
      выдача фактом не является** и подтверждается обратным запросом.

   Установка: символической ссылкой из `.git/hooks/pre-commit`. Команда установки печатается
   последней строкой скрипта — диагностика за собой не убирает.

3. **`tools/hooks/selftest.sh`.** Гоняет **каждую** проверку отдельно на заведомо падающем и
   заведомо проходящем входе, в одноразовой песочнице. Печатает построчный результат и итоговую
   строку «провалено N». Пер-проверка, не пер-хук: агрегированный результат скрывает, какая именно
   проверка сломалась.

   **Четыре требования к самотесту, снятые с оригинала. Без них самотест — театр:**

   - **Отрицательный случай обязан упасть ИМЕННО на хуке.** Недостаточно «коммит не прошёл»:
     в выводе обязана быть строка отказа хука. Иначе посторонний сбой окружения (нет git, нет прав,
     подпись коммита) читается как успешное срабатывание проверки. Это наш закон «успех инструмента
     не факт», вывернутый наизнанку.
   - **Проверка «строка исчезла» требует ИСТОРИИ коммитов** — одним снимком не покрывается. Нужен
     отдельный прогон на паре коммитов: сид кладётся в обход хука, судится только второй коммит.
     Три случая: строка исчезла без архива (падение) · строка переформулирована (проход) · строка
     исчезла вместе с архивом (проход).
   - **Фикстура проверяется сразу после записи** — наличием символа И дампом байтов. Кириллический
     символ в фикстуре собирается **восьмеричным экранированием**, а не литералом: литерал в
     коммитимом файле сам есть нарушение проверяемого правила и попал бы в репозиторий. У донора
     сломанная фикстура однажды обнулила целый кейс, и это осталось названным уроком.
   - **Три оси, а не одна.** (i) **Локаль** — байтовая и многобайтная; **локаль подбирается
     функциональной пробой, а не по имени из списка**: несуществующее имя молча откатывается
     в байтовую, и ось окажется непроверенной при зелёном выводе. Многобайтной локали не нашлось —
     это не провал, но обязано быть напечатано словами. (ii) **Размер** — файл больше буфера пайпа
     (более 64 КиБ), ловит ловушку 3. (iii) **Легитимный композит** — строки, дословно
     встречающиеся в нашем репозитории, ложно срабатывать не должны.

4. **Замер на реальном содержимом репозитория** — обязательный, и в обе стороны:
   - подложный коммит (файл с неверной первой строкой) реально завален — сохранить лог отказа;
   - попытка закоммитить строку с раскрытым паролем завалена проверкой 7 — сохранить лог; значение
     пароля в артефакт замера **не переносить**, фиксировать только факт срабатывания и номер
     строки;
   - **обратный замер:** коммит текущего дерева проходит хук без единого срабатывания — сохранить
     лог. Синтетика доказывает, что проверка умеет краснеть, и не доказывает, что она не краснеет
     на легитимном входе.

5. Локальный коммит: `method: commit hook, selftest, session status (M-4)`.

## Приёмка (критерии done)

- [ ] `tools/hooks/selftest.sh` печатает **«провалено 0»**, и в выводе видна отдельная строка на
      каждую из семи проверок, **в каждой из проверенных локалей**. Если многобайтная локаль не
      нашлась — это напечатано словами, а не умолчано.
- [ ] В выводе самотеста видны обе стороны каждой проверки: строка `bad` и строка `good`. Проверка,
      у которой предъявлена только одна сторона, приёмкой не закрыта.
- [ ] Отрицательные случаи упали **на хуке**, а не на окружении — это различие напечатано самим
      самотестом, а не выведено глазами.
- [ ] Лог отказа подложного коммита предъявлен.
- [ ] Лог отказа коммита со строкой секрета предъявлен (без значения секрета).
- [ ] Лог чистого прохода коммита текущего дерева предъявлен: **ноль срабатываний на легитимном
      входе**.
- [ ] `tools/session_status.sh` на чистом дереве печатает «ЧИСТО» и возвращает код 0.
- [ ] Проверка гомоглифов не срабатывает на обычной русской прозе документов — замер на реальном
      содержимом, с печатью числа срабатываний (ожидается ноль).
- [ ] Ни один критерий не закрыт по коду возврата: у каждого предъявлен лог.
