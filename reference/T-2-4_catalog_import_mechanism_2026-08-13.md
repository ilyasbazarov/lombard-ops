# T-2-4 · Механизм приёма справочника ликвидности — замер импортёра

**Дата:** 2026-08-13 · **Роль:** архитектор · **Класс:** A (написание кода без применения)
**Зачем:** формулировка «либо владелец кидает файл» задачей не является — не названо, как файл
попадает в работу, куда ложится и что делается дальше. Механизм назван целиком и предъявлен
четырьмя прогонами, включая отрицательные.

## Механизм — четыре шага, три из них наши

1. **Владелец:** Google Sheets, лист «Справочник» → Файл → Скачать → CSV. Один раз; квартальное
   обновление — тем же путём.
2. **Владелец:** кладёт файл ровно в `data_inbox/vehicle_catalog.csv`. Путь фиксирован, шаблон
   шапки лежит рядом (`data_inbox/vehicle_catalog.template.csv`). Каталог в `.gitignore` целиком,
   кроме шаблона: скупочные цены — коммерческая информация клиента, репозиторий публичный (`00 §4`).
3. **Скрипт `tools/catalog_import.py`:** проверяет шапку, нормализует значения (эмодзи класса →
   `green`/`yellow`/`red`, `«75%»` → `0.75`, `«$18,000»` → `18000`, прочерк → пусто), печатает счёт
   принятых и отклонённых строк с причиной по каждой, пишет сид `vehicle_catalog_seed.json`.
4. **Заливка сида в BigQuery** — шаг класса B по карточке, в приёмке `T-2-4`.

## Прогон 1 — файла нет: печатается CONTEXT GAP, а не тишина

```
$ python3 tools/catalog_import.py
CONTEXT GAP: файл справочника ликвидности отсутствует и угадыванию не подлежит.
  ожидался путь : data_inbox/vehicle_catalog.csv
  как получить  : Google Sheets, лист «Справочник» → Файл → Скачать → CSV
  ожидаемая шапка (порядок колонок обязателен):
    Марка,Модель,Ликвидность,LTV макс,Скупочная база,Комментарий
  скупочные цены — коммерческая информация клиента: каталог data_inbox/ в .gitignore,
  в публичный репозиторий файл не уходит (00 §4).
код возврата: 2
```

## Прогон 2 — три строки владельца (его же пример, дословно): принято 3, отклонено 0

```
$ python3 tools/catalog_import.py --input /tmp/cat_ok.csv --output /tmp/cat_seed.json
шапка совпала: Марка,Модель,Ликвидность,LTV макс,Скупочная база,Комментарий
строк принято : 3
строк отклонено: 0
распределение по классам: green=1, red=1, yellow=1
сид записан: /tmp/cat_seed.json (3 строк)
код возврата: 0
```

Сид (фрагмент, обе крайности — зелёный с ценой и стоп-класс без неё):

```json
{ "make": "Toyota", "model": "Camry 70", "liquidity_class": "green",
  "ltv_max": 0.75, "buyout_price": 18000.0, "max_loan_by_catalog": 13500.0,
  "comment": "Уходит за 3 дня", "source_row": 2 }
{ "make": "Range Rover", "model": "Sport", "liquidity_class": "red",
  "ltv_max": null, "buyout_price": null, "max_loan_by_catalog": null,
  "comment": "Не берём", "source_row": 4 }
```

**Стоп-класс без LTV и цены дефектом строки НЕ считается:** «не берём» и есть значение. Обратное
правило (зелёный или жёлтый без LTV либо без цены) — отклонение, см. прогон 4.

## Прогон 3 — обратный контроль исправности: битая шапка

Одна буква в имени колонки (`LTV max` вместо `LTV макс`) — отказ с печатью ОБЕИХ сторон:

```
ОТКАЗ: шапка не совпала. Обе стороны печатаются целиком:
  ожидалось: ['Марка', 'Модель', 'Ликвидность', 'LTV макс', 'Скупочная база', 'Комментарий']
  в файле  : ['Марка', 'Модель', 'Ликвидность', 'LTV max', 'Скупочная база', 'Комментарий']
код возврата: 2
```

## Прогон 4 — обратный контроль: битые строки называются номером и причиной

```
шапка совпала: Марка,Модель,Ликвидность,LTV макс,Скупочная база,Комментарий
строк принято : 1
строк отклонено: 3
  строка 3 — класс ликвидности не распознан: «фиолетовый»
  строка 4 — класс green требует и LTV, и скупочную базу
  строка 5 — скупочная база — не число: «дорого»
распределение по классам: green=1
```

Пустая строка листа пропускается молча и в счёт отклонённых не идёт — это форматирование таблицы,
а не дефект данных.

## Что скрипт НЕ делает намеренно

- не ходит в сеть за листом: доступ к Google Sheets API — новый облачный ресурс и новый доступ,
  а квартальное обновление руками стоит одной минуты;
- не грузит в BigQuery сам: заливка — класс B, идёт отдельным шагом по карточке;
- не пишет `max_loan_by_catalog` в таблицу: производная величина считается, а не хранится
  (принцип 1 конституции). В сиде она печатается для проверки глазами.
