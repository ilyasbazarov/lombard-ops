# КАРТОЧКА ПОДТВЕРЖДЕНИЯ · `Q-27` — права на файле подписанного токена · 2026-08-18

**Класс B.** Сервер клиента, исполняет владелец лично по RDP. Сессия ассистента команд не запускает.
**Вариант A** разбора (`ADJ`-ответ 2026-08-18): чинится КАТАЛОГ, не файл, — токен пересоздаётся
каждым прогоном, и точечные права на нём слетят при первом же удалении файла.

## Что исполняется, на каком объекте, чем откатывается

| | |
|---|---|
| **Что** | Разрыв наследования прав на каталоге ключей агента; удаление группы локальных пользователей из его списка доступа; явная выдача прав служебной учётке агента |
| **На каком объекте** | Сервер ERP `WIN-RSAGM3JEOUA`, каталог `C:\LombardAgent\keys` |
| **Чем откатывается** | Снимком списка доступа, снятым шагом 0 в файл `C:\LombardAgent\acl_keys_backup_2026-08-18.txt`, командой `icacls "C:\LombardAgent" /restore` (шаг «Откат» ниже). Резервный путь — включить наследование обратно одной командой |
| **Чем рискуем** | Единственный реальный риск — отобрать у агента право писать токен, тогда плановый прогон `03:00` упадёт. Поэтому шаг 4 проверяет прогон ВРУЧНУЮ до конца работы, а не «утром посмотрим» |
| **Чего НЕ трогаем** | `private_key.pem` и `credentials.json` — у них наследование уже разорвано (замер 2026-08-17), новые права каталога на них не распространятся; база PawnShop; облачные ресурсы; код агента |

## Почему это надо чинить

Замер `icacls` 2026-08-17 (`reference/T-0-8_step7_negative_probes_2026-08-17.md`, раздел 6):
`C:\LombardAgent\keys\signed_jwt.txt` несёт `BUILTIN\Пользователи:(I)(RX)`. Токен —
**предъявительский**: приватный ключ для его использования не нужен. Цепочка последствия названа
целиком: чтение файла любым локальным пользователем сервера в пределах TTL (600 с) → обмен на
федеративные облачные учётные данные → доступ к хранилищу секретов → **пароль read-only учётной
записи `LOMBARD_RO` к базе клиента** (`connector/agent/run_daily.py` читает секрет
`firebird-readonly-creds` именно этими учётными данными).

## Команды — PowerShell **от имени администратора**, по одной, вывод каждой сохранить

Группа берётся по SID `*S-1-5-32-545`, а не по имени: на русской Windows имя локализовано
(`BUILTIN\Пользователи`), и команда по имени отработает не везде одинаково.

**Шаг 0 — снимок «до» (он же откат).**
```
icacls "C:\LombardAgent\keys"
icacls "C:\LombardAgent\keys\*"
icacls "C:\LombardAgent\keys" /save "C:\LombardAgent\acl_keys_backup_2026-08-18.txt" /t /c
```

**Шаг 1 — разорвать наследование на каталоге, сохранив текущие права как явные.**
```
icacls "C:\LombardAgent\keys" /inheritance:d
```

**Шаг 2 — убрать локальных пользователей и явно выдать права агенту.**
```
icacls "C:\LombardAgent\keys" /remove:g *S-1-5-32-545
icacls "C:\LombardAgent\keys" /grant "WIN-RSAGM3JEOUA\lombard-agent-svc:(OI)(CI)(M)"
```

**Шаг 3 — проверка «после» на существующем файле.**
```
icacls "C:\LombardAgent\keys"
icacls "C:\LombardAgent\keys\signed_jwt.txt"
```

**Шаг 4 — РЕШАЮЩАЯ проверка: файл, созданный заново, тоже без лишних прав.**
```
schtasks /run /tn "LombardAgentDailyRun"
```
Подождать завершения (около минуты), затем:
```
icacls "C:\LombardAgent\keys\signed_jwt.txt"
Get-ChildItem C:\LombardAgent\logs | Sort-Object LastWriteTime -Descending | Select-Object -First 4 Name, LastWriteTime
```

## Что считается зачётом — предъявляется ЛОГОМ, не кодом возврата

1. Шаг 3: в выводе по каталогу и по файлу токена **нет строки `Пользователи`** (ни `BUILTIN\Пользователи`,
   ни `BUILTIN\Users`). Остаться должны СИСТЕМА, Администраторы, `lombard-agent-svc`.
2. Шаг 4: после реального прогона **тот же вывод по пересозданному файлу — снова без `Пользователи`**.
   Это и есть отличие варианта A от точечной правки: пересоздание не возвращает дыру.
3. Шаг 4: прогон **отработал штатно** — свежие файлы логов появились, в `*.err.log` нет ошибки
   доступа к `C:\LombardAgent\keys`.
4. Обратный контроль исправности инструмента: вывод `icacls` по `private_key.pem` по-прежнему
   печатает свои две строки — значит команда читает права, а не молчит.

**Пустой или непарсимый вывод при нулевом коде возврата — гэп наблюдения, а не «всё хорошо».**

## Откат (если шаг 4 показал отказ доступа)

```
icacls "C:\LombardAgent" /restore "C:\LombardAgent\acl_keys_backup_2026-08-18.txt"
```
Резервный путь, если восстановление из файла не отработает:
```
icacls "C:\LombardAgent\keys" /inheritance:e
```
После любого отката — повторить `schtasks /run /tn "LombardAgentDailyRun"` и убедиться, что прогон
проходит. **Вопрос `Q-27` при откате остаётся открытым** — это нормальный исход, а не провал.

## Что вернуть в сессию

Вывод всех команд шагов 0, 3 и 4 дословно. По ним закрывается строка `Q-27` в реестре и правится
строка прав в `11_INFRA_FACTS.md` (сейчас она называет ограниченным только файл приватного ключа —
это уже неверно, ограничены два файла, а после этой карточки будет ограничен каталог).
