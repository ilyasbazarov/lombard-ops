# M-1 · Артефакт замера мандата · 2026-08-08

Сессия исполнителя M-1. Коммит на входе: `3b6f75238e5c20ea71db43f217380d5299dd8f27`.
Написаны и закоммичены: `.claude/settings.json`, `.claude/agents/architect.md`,
`.claude/agents/generator.md`, `.claude/agents/executor.md`.

## 1. Замер «законы подхватываются» (шаг 3 брифа) — НЕ СНЯТ, гэп канала

Требование брифа: свежая сессия ролью архитектора, без вставки контекста, печатает перечень
фактически прочитанных документов; в перечне обязан быть `05_CONVENTIONS.md`.

**Факт 1 — реестр ролей фиксируется при старте процесса.** Попытка поднять роль субагентом из
текущей сессии (файлы ролей уже записаны на диск) вернула дословно:

```
Agent type 'architect' not found. Available agents: claude, claude-code-guide, Explore,
general-purpose, Plan, statusline-setup
```

Роль, созданная посреди сессии, этой сессии недоступна — она станет видимой только процессу,
запущенному после коммита файлов ролей.

**Факт 2 — свежий процесс из-под исполнителя не авторизован.** Обе попытки
(`claude --agent architect -p "…"`, в песочнице и без) вернули дословно:

```
Exit code 1
Not logged in · Please run /login
```

**Вердикт по шагу 3: перечень прочитанных документов свежей сессией НЕ получен.** Это гэп канала
замера, а не факт о файлах ролей: исполнитель не располагает авторизованным способом запустить
свежую интерактивную сессию. Замер выполняется владельцем: новая сессия инструмента, первое
сообщение — одно слово роли, просьба напечатать перечень фактически прочитанного. Приёмка M-1
остаётся открытой до этого лога.

## 2. Замер мандата класса B (шаг 4 брифа) — гейт НЕ СРАБОТАЛ

Отдельное сообщение перед попыткой (что исполняется, на каком объекте, чем откатывается) дано.
Владелец заранее объявил, что отклонит диалог подтверждения.

Попытка `git push` из работающей сессии. Вывод инструмента дословно, целиком:

```
To https://github.com/ilyasbazarov/lombard-ops.git
   ad78bef..3b6f752  main -> main
```

**Диалог подтверждения в логе исполнителя не наблюдался; отклонения, объявленного владельцем,
не произошло; публикация состоялась.** Наружу ушёл ранее существовавший локальный коммит
`3b6f752` (docs-правки, санированные по ADR-001); файлы этой сессии на момент попытки закоммичены
не были и не публиковались. Откат не выполнялся: он требовал бы принудительной перезаписи remote,
запрещённой и настройкой, и здравым смыслом.

**Интерпретация (отделена от факта):** `.claude/settings.json` с правилом «спрашивать `git push`»
был записан этой же сессией; настройки применяются при старте процесса, поэтому к уже работающей
сессии правило не применилось. Гейт в СВЕЖЕЙ сессии этим замером не подтверждён и не опровергнут —
он снимается тем же замером владельца, что и п.1: в свежей сессии `git push` обязан упереться
в диалог.

## 6. Остаток до закрытия M-1

Один замер владельца в свежей сессии инструмента закрывает оба открытых пункта приёмки:
1. первое сообщение — слово роли, попросить перечень фактически прочитанных документов
   (ожидается `05_CONVENTIONS.md` в перечне);
2. там же — попытка `git push`, отклонить; лог диалога — сюда, в этот файл.
