# audit — локальный каталог артефактов первичного аудита (НЕ КОММИТИТСЯ)

**Заведён `ADR-063`, вариант A развилки размещения.** Содержимое каталога в `.gitignore` целиком;
в репозиторий уходит только этот файл-опись.

## Почему не в репозиторий

Репозиторий публичный (`00 §4`). Артефакты аудита содержат данные бизнеса клиента: реестр
заключённых договоров за 12 месяцев (454 договора), историю проданных невыкупов, отчёт о прибылях
и убытках с балансом. Ни сырьё, ни аппендиксы, ни переносимое ядро сюда не коммитятся — ни целиком,
ни выдержками с построчными суммами.

## Что кладётся сюда владельцем

Имена файлов **не меняются**: имя есть часть провенанса, переименование рвёт связь с пирамидой
артефактов аудита.

| Уровень | Что | Пример имени |
|---|---|---|
| 0 | сырьё: реестры, выписки, отчётность | как выгружено |
| 2 | аппендиксы по доменам | `APP_A_portfolio.md`, `APP_B_*.md`, … |
| 3 | переносимое ядро | `AUDIT_STATE_v*.md` |
| 4 | итоговый отчёт клиенту | как назван |

## Что происходит дальше — два шага, второй назначается по факту прочтения

1. **Карта аудита** уезжает в публичный репозиторий отдельным документом: какие блоки есть, что в
   каждом, статус, где лежит источник, какие утверждения из него уже употребляются в наших
   документах и с какой датой. **Без единой построчной цифры клиента.** Проект получает оглавление
   своего основания, а не его содержимое.
2. **Извлечение входов** — что именно берётся как вход задач — назначается ПОСЛЕ прочтения, а не
   заранее (`05 §I`, третий класс гэпа: до предъявления артефакта запрещено назначать его схему).

**После решения о вычисляемом справочнике (`ADR-062`) переносить данные аудита в проект больше не
нужно:** доли невыкупов по маркам витрина `T-1-6` пересчитает из базы живьём и свежее июньского
среза. От аудита остаётся нужным знать, что в нём есть, и пометить всё, что из него уже утекло в
наши документы (`ADR-063`, R4).

## Ограничения

- Каталог локальный: не версионируется, не переживает переклонирование, на другой машине его нет.
  Это принятая цена варианта A. Версионирование аудиту не нужно — он завершён и не меняется.
- Потребность во второй машине или в истории правок есть условие оживления варианта B (приватный
  репозиторий-сателлит).
